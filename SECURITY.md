# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email: ramakrishnaa1967@gmail.com

Include:
- Description of the vulnerability
- Steps to reproduce
- Affected component (SDK, collector, API, dashboard)
- Potential impact

You will receive a response within 72 hours. If confirmed, a patch will be released within 14 days for critical issues.

## Scope

In scope:
- Authentication bypass
- Cross-tenant data access
- Remote code execution
- Credential exposure
- Injection vulnerabilities (SQL, prompt, command)

Out of scope:
- Vulnerabilities in third-party dependencies (report to them directly)
- Issues requiring physical access
- Social engineering

## Disclosure

We follow coordinated disclosure. Please allow 90 days before public disclosure to give us time to patch and notify affected users.
